# 지금 어느 역

지하철에서 지금 어느 역인지 보여주는 웹앱. 내 위치로 가장 가까운 역을 찾고, 도착역을 정하면 환승과 하차를 알려준다.

- 실시간 열차 위치: 서울특별시 공공데이터 (서울 열린데이터광장, 공공누리 1유형)
- 노선 데이터: © OpenStreetMap contributors (ODbL), kimmdr2/metroscope의 network.json에서 역 이름·순서·좌표를 추림
- 지도의 나무·건물·명소 모형은 장식이며 실제 건물 위치가 아니다
- 소요 시간은 역간 2분, 환승 5분으로 잡은 추정치다

## 구조
- `index.html` — 배포되는 웹앱 한 파일 (빌드 결과물)
- `src/` — 원본: 화면 템플릿(`markup4.py`), 노선·경로 계산(`helpers4.js`, `class4.js`), 노선 데이터(`net3.json`), 화면 그리기·위치·알림(`host.js`)

## 위치를 아는 방법 (우선순위)
1. 실시간 열차 위치 — 내가 탄 열차를 찾아 열차 번호로 따라간다 (`relay/worker.js` 중계 필요)
2. 안내방송 듣기 — 마이크 버튼을 켜면 탑승 직후·환승 후·내리기 전 구간에만 잠깐 듣고 역 이름을 찾는다. 녹음은 저장하지 않는다
3. 위치(GPS) — 역 근처에서 잡히면 맞춘다
4. 시간 추정 — 역간 평균 110초. 환승역에서는 멈추고 다시 탑승을 기다린다

## 실시간 열차 위치 켜기
1. 서울 열린데이터광장에서 '실시간 지하철' 인증키를 받는다 (키 하나당 하루 1,000회)
2. 중계 서버를 하나 띄운다 (둘 중 하나)
   - Vercel: GitHub로 로그인 → 이 저장소 가져오기 → 환경 변수 `SEOUL_KEY` → 배포. 주소는 `https://<프로젝트>.vercel.app/api/trains`
   - Cloudflare Workers: `relay/worker.js`를 붙여 넣고 암호 변수 `SEOUL_KEY`
3. 웹앱 주소 뒤에 `?rt=<중계 주소>` 를 붙여 한 번 연다 (기기에 저장됨)
